# 公众号医学漫画长图技能

根据一个中文医学科普标题，生成五张 821×1916 的漫画长图、约 300 字总结，以及可复制到微信公众号编辑器的本地排版预览。

## 学员安装

在 Codex 中输入：

```text
$skill-installer
从 GitHub 仓库 <你的 GitHub 用户名>/wechat-medical-comic-series 安装路径 wechat-medical-comic-series
```

安装完成后，下一轮对话即可调用：

```text
$wechat-medical-comic-series
标题：关于血压数值，这 4 个问题建议一次弄明白
```

## 发布者推送

1. 在 GitHub 新建公开仓库：`wechat-medical-comic-series`。
2. 在本目录运行 GitHub 提供的推送命令，或使用 GitHub Desktop 发布。
3. 将仓库链接与上面的安装指令发给学员。

技能内含五种长图版式参考。涉及医疗内容时会要求核对当前权威资料，且不会自动发布到公众号。
